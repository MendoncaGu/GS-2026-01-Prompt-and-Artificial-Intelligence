# Como o sistema funciona?

Este código foi desenvolvido para ser um assistente virtual chamado Mission Control AI, responsável por analisar dados de uma missão espacial armazenados em um docx. utilizando a Inteligência Artificial da OpenAi “Chat gpt 4o mini” para encontrar as informações mais relevantes dentro do documento e gerar relatórios sobre o estado da espaçonave.
